# 提炼层提示词模板（因子蒸馏 · 每书一子代理）

> 本文件固化提炼层（OCR 文本 → Alpha 因子卡）使用的标准提示词模板与设计意图。
> 因子卡的格式与分类定义见 `SKILL.md` §二；builder 代码规范见 `factor-builder-api.md`；
> 四类回测细节见 `backtest-timing/cross-section/rotation/screening.md`。

## 一、标准模板

```
你在 <项目根目录> 项目中做「投资书籍 → Alpha 因子提炼」。

任务：阅读 factor_gen/<书名>/ocr/full.txt（《书名》N 页，OCR 文本约 X 字符——<一句话书的定位>），
产出两个文件：

1. factor_gen/<书名>/summary/AI总结.md
   逐章/板块总结：书的结构、核心交易理念、关键方法。800~1200 字。

2. factor_gen/<书名>/alpha/因子列表.md
   从书中提炼**可量化的 Alpha 因子**，严格按此格式：

   ### F01. 因子名称
   - **类型**: timing | cross_section | rotation | screening
   - **定义**: 一句话
   - **构建**: 具体公式/逻辑（含明确阈值）
   - **频率**: daily | weekly | monthly
   - **数据需求**: 所需字段列表
   - **原文依据**: 引用原文（页码或段落）

   类型说明：timing=大盘/市场情绪择时信号；cross_section=个股打分排序；
   rotation=行业/板块轮动；screening=条件筛选股票池。

提炼纪律（重要）：
- 只提炼**可量化**的规则：必须有明确的条件/阈值/计算公式（如"连续3日涨停且换手率>20%"）。
- 纯心态/哲学（"控制回撤""不要贪婪"）不提炼。
- 每个因子必须有原文依据。
- 若某类内容无法量化，不要硬凑。没有因子就明确写"无可提炼因子"并说明原因。

可用数据（构建因子时不要超出这些字段）：
- 个股日行情：date/stock_id/open/high/low/close/volume/amt/pct_chg/adj_close/
  max_updown_close(涨跌停标记)/trade_status
- 市值/股本（tot_share_cap/float_share_cap）、TTM 财务（ROE 等）
- 指数日线（沪深300/中证500/中证1000/国证2000）、中信一级行业指数（30个）
- 不可用：龙虎榜、封单量/封板时间、分钟级行情、概念板块

阅读方法：full.txt 每页以 `===== 第 N 页 =====` 分隔。文件较大，先扫结构（开头/目录/章标题），
再重点精读含具体规则/数字/条件的章节。因子质量优先于数量。
注意 OCR 可能有少量错字，理解时容错。

完成后，你的最终回复只需：因子数量 + 因子ID和一句话名称列表 + 一句话评价此书因子提炼价值。
不要贴完整文件内容。
```

## 二、结构块与设计意图

| 提示词块 | 针对的失效模式 |
|----------|----------------|
| 任务与双产物 | 总结给人读、因子卡给机器解析——防止总结与数据混为一谈无法自动化 |
| 因子格式硬约定（六字段） | 格式随意导致 `aggregate_factors.py` 正则解析失败；definition/construction 是 factor_meta 的 NOT NULL 列 |
| 提炼纪律（四条） | 鸡汤变假因子；硬凑凑数；不给"零因子"体面退出 |
| 数据边界 | 提炼出龙虎榜席位跟踪等数据拿不到的空中楼阁因子 |
| 阅读方法 | 大书顺序读导致上下文爆掉；OCR 错字误读 |
| 回复约束（只回摘要） | 保护主会话上下文（28 本书并行调度时至关重要） |

## 三、深度推断模式（明示之外的可选补充）

> 动机：书的深层价值往往不在明示规则，而在作者反复强调却从未量化的**隐含主题**
> （如巴菲特的"护城河"）。允许 LLM 做有证据链约束的推断，但要与"硬凑"严格区分。

在标准模板后追加以下块：

```
## 深度推断模式（在明示因子之外补充，不设数量下限）

除原文明示规则外，允许产出**推断型因子**：作者反复强调但从未量化的底层主题，
由你设计可计算的刻画方式。流程：

1. 先在心里列出本书的"隐含公理"清单——作者在多章/多年反复表达、贯穿全书
   的价值观或模式判断（如巴菲特对"竞争优势/护城河"的执着）。
2. 对每个公理自问："如果作者是对的，市场上应该能观察到什么可计算的现象？"
3. 设计代理变量与阈值，因子卡在六字段之外额外加：
   - **来源类型**: 推断
   - **推断逻辑**: 一句话说明为什么这个代理变量能刻画该主题
   - **原文依据** 写证据链：≥2 处不同章节/年份的原句支撑该主题
4. 阈值是你的设计值，必须在构建栏标注"参数需回测校准"。
5. 只有 1 处孤证的推断不要写；与作者明确表述矛盾的方向不要写。
```

**与硬凑的边界（质检用）：**

| | 硬凑（禁止） | 深度推断（允许） |
|---|---|---|
| 原文支撑 | 无/单点孤证 | ≥2 处不同章节独立印证 |
| 声明 | 伪装成作者明示 | 显式标注"来源类型：推断"+推断逻辑 |
| 阈值 | 含糊 | 标注"设计值，需回测校准" |

**下游处理：**
- 因子卡新增两个可选字段（`来源类型`、`推断逻辑`），解析器原样透传进 factor_meta.notes
- 证据链 <2 处的推断因子在解析阶段拒收
- 精选报告中推断因子需单独标记，且建议先过参数稳健性检验

## 五、按书微调变体

| 书型 | 追加指令 |
|------|----------|
| 威科夫/量价类（概念无阈值） | "Spring 等概念需转化为明确量价公式才算可量化，**阈值由你设计参数化版本**并在构建栏写清公式" |
| 百万字级战争史/纪实 | "**严禁顺序通读**，用关键词定位'战法/模式/规律/复盘'密集段落精读，叙事略读" |
| 交割单 | "单笔交割单不是规则，但**买卖点注解中反复出现的模式**凡能转成条件的一定抓住" |
| 多人合集（48位/56位/语录） | "原文依据必须注明出处人物；与其他合集重叠无需顾虑，汇总层去重" |
| 非投资书 | 直接允许"无可提炼因子"结论+判定依据（关键词扫描+人工抽样复核） |

## 六、产出物的下游契约

- `因子列表.md` 由 `scripts/aggregate_factors.py` 解析：标题行 `### Fnn. 名称` + 子弹字段
  `- **字段**: 值`（续行拼接），字段别名表（类型/定义/构建/频率/数据需求/原文依据）。
- 入库后 factor_id = `<书码>-F<nn>`（书码见 aggregate_factors.py 的 BOOK_CODES）。
- factor_meta 中 definition、construction 为 NOT NULL——提炼时必须写全，缺了会在入库时告警。
